# Option A：面板设计与 design token

面板的视觉方向 A「胶囊」：大词头、紫色胶囊标签、纯图标操作、左下状态胶囊、紫色实心主按钮。
本目录的 `card.html`、`read.html`、`proof.html`、`out.html`、`system.html` 是设计稿源文件（Design 画布的 `.dc.html` 格式，依赖画布运行时，不能单独在浏览器打开），每个文件把一个场景的所有子状态竖排画出来。
具体像素值以设计稿为准；本文件定 token，实现时所有颜色、字号、间距、圆角都从 token 取，视图里不出现裸数值。

设计稿只画了浅色。
深色值是本文件给的，原则是同一层级的对比度不低于浅色。

## 字体

系统字体（SF Pro / 苹方），不引入字体文件。

| token | 字号 / 字重 | 用途 |
|---|---|---|
| `headword` | 28 / bold，字距 -0.4 | 卡片词头 |
| `result` | 17 / medium | 译文、外译结果 |
| `proofread` | 16 / regular | 校对正文和 diff |
| `title` | 15 / semibold | 「本句」释义、通知标题 |
| `body` | 15 / regular | 释义、输入框 |
| `callout` | 14 / regular | 原文、等待中的提示、卡片的其他义项和例句 |
| `secondary` | 13 / regular | 原句、回译、通知说明 |
| `button` | 13 / semibold | 胶囊按钮的标题 |
| `note` | 12.5 / regular | 结果下的说明、操作提示 |
| `pill` | 12.5 / semibold | 胶囊 |
| `label` | 11.5 / semibold | 区块小标题（本句、例句、搭配） |
| `caption` | 11 / semibold | 小胶囊（常用、少见）、键帽 |

上表就是 `Theme.swift` 里的 `Typography`，`ThemeTests` 检查两边一致。
只有卡片用的字号留在 `CardView.swift`：放不下一行时的词头 22 / bold、词性 12 / semibold、搭配 14 / semibold、音标前的 US/UK 标签 10.5 / semibold。
设计稿里「本句」释义是 16、其他义项的小标题是 12；实现统一用 `title` 15 和 `label` 11.5，不为 1 pt 的差别多开 token。

## 间距与圆角

- 面板圆角 18，内边距左右 22、上 22、下 16（底栏在内边距里）。
- 区块之间 16，行之间 10，胶囊与文字之间 12。
- 重点区块圆角 12、内边距 12×14；胶囊全圆角；词性胶囊圆角 6、最小宽 44、居中；US/UK 标签圆角 4、中性色。
- 图标按钮 32×32、圆角 8、图标框 18（SF Symbol 15 pt、light 字重、空心符号，接近设计稿的细线条）；主按钮胶囊高 32、左右 14、白字、带 ↩ 键帽。

## 组件

- **胶囊 `Pill`**：紫（词性、状态、次数）、绿（常用、没有错误）、橙（问题、未完成）、灰（少见、不能替换）四种色调。
- **图标按钮 `IconButton`**：只有图标，悬停时 tooltip 显示「标题 快捷键」，无障碍标签同。
- **主按钮 `PrimaryButton`**：紫色实心胶囊，标题加键帽，响应 ↩。
- **底栏**：左边一个状态胶囊（次数、纠错摘要、译成外语），右边图标按钮，有主操作时主按钮在最右。
- **重点区块 `TintedBlock`**：`accentBlock` 底，内含 `label` 小标题。

## 各场景要点

- 查词：词头行右侧星标按钮（要学 ⌘S，已标要学时实心紫星）；音标前「US/UK」中性小标签；词性胶囊列；「本句」在重点区块里，原句中被查的词用 `highlight`；底栏左「第 N 次」胶囊，右边发音、作为句子翻译、更多。
- 翻译：原文次要色最多 4 行；结果 `result`；不完整时末尾加橙色「未完成」胶囊；说明行带按钮；单词或短语的译文在底栏右端有紫色浅底的「查这个词」按钮。
- 校对：底栏左边摘要胶囊（「已接受 3/4」、绿色「没有发现错误」、橙色「未替换」）；右边复制图标按钮和「替换 ↩」主按钮。
- 外译：回译在重点区块里；问题清单用橙色块；主按钮「替换 ↩」，有问题时变次级按钮「仍要替换 ⌘↩」。
- 系统态：输入框、读取中、失败、需要设置的图标放在 36 pt 圆形色调底上，按钮在右下，默认按钮用主按钮样式；「没有可查的内容」只是说明情况，图标底用中性色而不是橙色。
