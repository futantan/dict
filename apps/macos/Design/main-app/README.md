# 主应用窗口

Dict 原来只有菜单栏图标和浮动面板。
主应用是一个常驻窗口，汇集查询记录、生词本、复习和设置。
视觉沿用面板的 Option A，token 和组件见 `Design/option-a/README.md`、`App/Sources/Panel/Theme.swift`、`App/Sources/Panel/Components.swift`。

本目录的 `home.html`、`history.html`、`saved.html`、`review.html`、`settings.html` 是设计稿源文件（Design 画布的 `.dc.html` 格式，依赖画布运行时，不能单独打开），像素值以设计稿为准。
设计稿里的数字是示例数据。

## 形态

- 应用变成普通应用：Dock 里有图标，⌘Tab 能切到，菜单栏图标保留。
- 「在 Dock 中显示」「在菜单栏显示图标」各有开关，两个不能同时关。
- 关闭主窗口后应用继续在后台运行，读写快捷键照常工作；点 Dock 图标或菜单栏「打开 Dict」重新打开窗口。
- 原来单独的设置窗口并入主窗口的「设置」页，菜单栏「设置…」和 ⌘, 打开主窗口并选中设置。
- 引导窗口保留，完成后打开主窗口。

## 结构

左侧固定侧栏（宽 232），右侧内容区。

| 侧栏项 | 内容 | 数据 |
|---|---|---|
| 今天 | 搜索框（⌘K，回车在面板里查词或翻译）、今日概况、最近查询、反复遇到还没标要学的词 | `VocabStore.day(_:)`、遇到次数、`dueReviews` |
| 查询记录 | 按天分组的查词和句子记录，搜索，按类型和来源应用筛选，右侧详情显示当时的词卡和原句 | `encounter`、`sentence_event`、保存的 `card_json` |
| 生词本 | 标了要学的词，筛选、排序、导出 CSV / Anki，右侧列出遇到过它的原句 | `tier = learning`、`exportAnkiTSV` |
| 复习 | 用遇到过的原句做卡片，只有「忘了」「记得」两档，键盘 1 / 2 / 空格 | `dueReviews`、`recordReview`、`review_state` |
| 设置 | 通用、语言、模型、快捷键、写作、发音、权限、数据与隐私、关于 | 现有设置项，加上「通用」的四个开关 |

侧栏「生词本」后显示数量，「复习」后显示待复习数（为 0 时不显示）。
侧栏底部显示读、写两个快捷键。

## 新增的数据

- 标要学的时间：用于「本周新加」和生词本的「加入时间」排序。
- 「已熟悉」：复习连续记得到最高一档后归入，算法沿用现有 `review_state.step`。
- 其余全部来自已有表，不另建存储。
